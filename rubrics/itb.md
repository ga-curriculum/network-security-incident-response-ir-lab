## Lab requirements

The following requirements describe the necessary deliverables for the Network Security Incident Response (IR) Lab.

| Criteria                                                                                                              | Points |
| --------------------------------------------------------------------------------------------------------------------- | ------ |
| Your name, the slide deck's title, and the topic are present on an introductory slide.                                | 5      |
| The slide deck was shared publicly so that it can be viewed by the instructor on their first attempt when grading.    | 5      |
| The slide deck contains an audio and video presentation of the slide deck's main content.                             | 45     |
| The slide deck avoids unexplained jargon and acronyms.                                                                | 5      |
| The slide deck's content supports the verbal presentation instead of being a script.                                  | 5      |
| The presentation is delivered within the time limit provided.                                                         | 5      |
| Visual elements and design in the slide deck are professional.                                                        | 5      |
| The slide deck includes an overview of the incident.                                                                  | 5      |
| The slide deck includes relevant details about the incident response plan.                                            | 5      |
| The slide deck includes relevant details about the incident investigation.                                            | 5      |
| The slide deck includes details about the preventative measures that can be implemented to prevent similar incidents. | 5      |
| The slide deck includes summarizes the key learnings and next steps.                                                  | 5      |
| **Total possible points**                                                                                             | 100    |
